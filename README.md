# Onionz

Onionz builds your own search index of onion sites over Tor, on the phone itself, and searches it with no network requests. Encrypted, no accounts, no adverts. In beta.

Website: https://customgpter.github.io/onionz/

Download: https://github.com/CustomGPTer/onionz/releases/download/v0.2.0-beta1/Onionz.apk
